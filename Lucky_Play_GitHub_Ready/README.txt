LUCKY PLAY — GITHUB UPLOAD PACKAGE

Keep this exact structure:
  index.html
  music/
    lobby-track-1.mp3
    lobby-track-2.mp3
    lobby-track-3.mp3

HOW TO UPLOAD
1. Open your GitHub repository.
2. Upload index.html to the repository's main/root folder.
3. Upload the whole music folder (with all 3 MP3 files) to that same root folder.
4. Do not rename the music files or move the folder. The HTML uses these exact relative paths.
5. Open the deployed site. The background playlist starts after the first click/tap/key press because browsers block autoplay before user interaction.

The music plays in the Lobby and VIP Lounge only, follows the existing mute control, and stops when leaving those views.
All game coins are virtual and have no real-world value.
